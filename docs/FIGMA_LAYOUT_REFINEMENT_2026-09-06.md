# Figma 布局与信息密度优化

日期：2026-09-06。范围：用户明确指出问题主要在 Figma，本轮只交付设计稿优化，不同步生产代码。

## 问题与处理

- 捕获容器仍固定在旧宽度：例如外层素材面板 284 px，内部仍为 312 px；部分段落文字增高到 67 px，父容器仍只有 52 px。将实际段落、表单和列表改为明确的 Auto Layout / 内容自适应，避免旧捕获坐标继续控制新排版。
- 补齐窗口栏、Dock 面板、导航栏、Inspector、标题栏、操作区和工具组的分隔；沿用现有语义变量、字体与组件，不再用空白猜测区域边界。
- 剪辑页让素材列表成为左栏主内容，源预览与插入保持明确的展开入口；新增展开状态，保留预览、打点、V/A 与插入/覆盖/替换。
- Agent 首屏突出结果、作品状态及活动记录；文件路径等技术细节和分段说明保留在完整回复状态。修复段落和 bullet 的叠压，没有改写消息中的项目事实。
- 时间轴按编辑菜单、导航与吸附、范围与循环、修改审阅分组；弱化未选中片段的边框及狭窄片段的重复类型角标。30 个片段的横向位置与宽度未变。
- 资料库弱化常态状态和次级行操作，统一详情标签与值的轴线；长路径用省略显示，不再越过详情列。
- 回放页拆开玩家、武器、回合元数据与定位动作，完整显示速度选项；图例移离地图中心。
- 成品页使用 104 px 文件行、144×81 的真实片段缩略图和单一预览标识，路径单行省略；保留文件定位及来源任务入口。缩略图复用文件内对应真实片段图像，没有生成游戏画面。
- 导出表单的旧 Grid 列宽改为明确的标签/控件布局；高光列表独立滚动，分页留在画板内；首页去掉空待办标题与重复新建区域。
