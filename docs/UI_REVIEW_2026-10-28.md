# 页面审查与优化 · 2026-10-28

本轮由 8 个 subagent 分批并发审查，覆盖 14 个主路由、比赛工作区的 9 个视图、Steam 历史和设置的 5 个分节。沿用现有浅色蓝灰桌面设计、共享控件和唯一 Project Timeline；修改集中在状态准确性、操作可达性、文案和窄窗口阅读。

采用 [Humanizer](https://github.com/blader/humanizer/blob/main/SKILL.md)、[anti-ui-slop](https://github.com/discountry/ritmex-skills/blob/main/skills/anti-ui-slop/SKILL.md)、[technical-writing](https://github.com/jimyag/dotfiles/blob/main/skills/technical-writing/SKILL.md) 和本地 Impeccable 规范。产品约束以 `AGENTS.md`、`apps/web/PRODUCT.md` 和 `apps/web/DESIGN.md` 为准。

## 覆盖与修改

| 页面或模块 | 处理结果 |
| --- | --- |
| 工作台 | 列表加载具名，失败提供重新加载；精简环境提示，删除失效的新建作品查询参数。 |
| 作品列表 | 显示真实版本，统一创建与读取失败提示。 |
| 作品工作区 | 读取失败可重试；交付检查失败与没有可录片段分开；重录计入录制范围；输出入口保留作品筛选。 |
| 时间线 | 窄片段按可用宽度依次显示名称、回合标记、轨道序号；只有连序号也放不下时隐藏。时间几何与编辑身份不变。 |
| 成品文件 | 更新时间使用 `updated_at`；空态包含录制和导出两种来源；长文件名在删除确认中可换行。 |
| Demo 资料库 | 文件缺失时禁用分析和回放；提交中阻止重复操作；删除无依据的视图建议和恢复承诺。 |
| Steam 历史 | 读取失败不再显示空列表；未取得对应任务时禁用取消并说明原因；状态列统一，行操作沿用共享按钮。 |
| 选手目录与档案 | 失败、加载和无数据分开；热图失败不再提示先分析；包括没有可展示异常消息的失败情形。 |
| 证据检索 | 调整检索、批量与详情操作层级；筛选摘要可换行；注释改用正文字号并减少嵌套边框。 |
| 比赛概览与高光 | 精简重复说明，快捷键提示可换行。 |
| 复盘笔记 | 洞察采用分隔列表，不可用统计按需展开；点评保留换行；注释读取失败可重试且不显示伪零计数。 |
| 回合、单场选手、对位、道具与经济、回放、队伍 | 已检查源码与窄窗口截图，保留现有页面结构。 |
| 任务中心与详情 | 修正标题层级和重复 DOM ID；行链接使用 ghost 外观；取消后的重发说明依据实际能力；导出任务保留作品上下文。 |
| 设置与诊断 | 设置读取和编码器检查失败可重试；JSON 校验使用共享 Field 的错误关联；修改模型配置会清除旧连接结果。 |
| Steam 设置 | 已有凭据只在留空时复用，非空替换值仍校验；必填标记与保存语义一致。 |
| 恢复中心 | 部分扫描的零结果不再表示全量正常；清理范围和配置覆盖后果使用直接、完整的说明。 |
| 使用引导 | 第三步明确为创建作品；读取失败保持进度未知；不再承诺三步完成视频。 |
| 导航与命令面板 | 折叠导航统一浅蓝选中态；搜索区分加载、失败和无结果，保留可用结果，重试保留关键词并恢复输入焦点。 |
| 活跃文档 | 核对并修正绑定生成命令、按需回放和选材职责，合并重复启动说明。 |

## 验证边界

浏览器使用现有开发 fixture IPC，能够检查页面渲染与前端操作，不能证明真实 CS2/HLAE 录制、Steam 下载、模型连接或媒体导出成功。本轮没有运行这些外部集成，也没有修改 Rust 后端。

选手趋势截图中的日期顺序来自开发 fixture 的数组顺序。正式 SQL 按日期降序返回，趋势组件再反向绘制，因此没有将这一样例问题记为生产缺陷。地图底图和录制媒体的缺失同样按 fixture 范围判断。
