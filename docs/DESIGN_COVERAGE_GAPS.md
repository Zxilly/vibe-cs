### 3.3 壳层缺的态

- **命令面板 Ctrl+K 展开态** — `Frame` 只画了顶栏那个入口框，面板本体（搜索、结果分组、键盘提示、无匹配态）没画。状态机里明确写了它「可直达任意页面」，是主要导航手段之一。
- **右侧 Agent 竖条展开态** — `Frame` 只有 46px 收起态和「1 待确认」徽标，展开后是什么形态没画。这条决定了 Agent 在非 Agent 页面上怎么介入。
- **侧栏收起态** — 现有 `uiStore` 有 `sidebarCollapsed`，设计稿只有 216px 展开态。
- **本地服务离线的全局降级** — 顶栏有「本地服务在线」绿点，离线时整个应用怎么表现没画（现有代码里每个页面都有 `source !== 'service'` 分支）。

### 3.4 全局状态与浮层

- **空状态** — 资料库为空 / 未分析 / 检索无命中 / 无输出 / 无任务 / 素材库为空
- **加载态** — 路由级 Suspense、表格骨架、Replay 帧加载、热力图采样中
- **错误态** — `RouteError` 路由错误页、`NotFound`
- **持久提示 `Notice`** — 现有四态 info / success / warning / danger，设计稿里只在具体页面出现过实例，没有统一规范画板
- **对话框清单**（现有 `Drawer` / `role="dialog"` 使用点 + 顶栏按钮推断）：
  导入 Demo、监听目录、重新定位文件、列配置、保存为视图、存为预设、批量删除确认、移除记录确认、取消任务确认、玩家比较抽屉、证据注释抽屉

### 3.5 验收标准要求但没有参考画面的

来自 `PRODUCT_CAPABILITIES_AND_VISUAL_REDESIGN_BRIEF.md` §15：

- **暗色主题** — 你已决定派生一套暗色 token。设计稿 12 页全是浅色，希望至少给 1–2 页暗色参考（建议：01 工作台首页 + 10 多轨编辑器，一个浅一个重），否则暗色只能由我按 OKLCH 规则推导。
- **1100×700 最小窗口** — 全部画板按 1920×1080 绘制。§15.3 要求这个尺寸能跑完主流程。三栏布局（如 03 号稿：180 + 主区 + 380）在 1100 宽下必然要折叠，折叠规则需要设计判断。
- **200% 缩放** — 同上。

## 5. 已确认的技术决策（补完设计后据此出架构方案）

- 迁移策略：一次性全量重写（`src/` 全部重写，token + 基础组件 + 壳层 → 12 页 → 一次性回归 167 个测试）
- 主题：浅色 + 同时派生一套暗色 token
- 样式：Tailwind 4 `@theme` 映射 Industry token
