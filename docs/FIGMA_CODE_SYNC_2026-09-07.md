# Figma 设计到代码同步

日期：2026-09-07。承接用户“设计确保统一一致，操作性良好之后同步代码。分块 commit push。”

设计入口：[流程与状态审查](https://www.figma.com/design/N05FPVtPTwWV3ONlE48Fwv?node-id=708-22918)。本轮把此前仅在 Figma 表达的布局、信息密度和操作状态同步到现有 React/Tauri 实现，而不是把示例数据和原型快捷键搬入产品。

## 实现

- 使用既有浅色蓝灰主题、字体、Button、Dialog、Drawer 与 Dock。没有新增页面私有样式表或第二套 Timeline / Agent 实现。
- 高光列表、批量加入和 Inspector 共用同一来源映射；补齐原先详情动作缺少的选手 ID 与 tick rate。URL 明确保留高光身份，回放移动播放头不会改换所选高光。
- 加入确认展示真实事件和录制范围、缓冲说明、目标作品、Story 末尾和总时长。无效范围禁止提交，失败重试沿用已创建的作品，数据刷新不会替换用户选择。
- 作品级任务查询在存储分页前过滤 project_id，计数和汇总也按作品隔离；顶部状态和 Agent 卡片共用展示。重新进入页面可以恢复任务，且不会自动继续旧 Agent 对话。
- 素材列表为左栏主要区域，源预览可展开；源文件重新定位不会清空面板选择和展开状态。Program 控制框统一，暂停文字明确，录制片段的非选中边框和角标弱化。
- 窄窗口使用同一面板工厂及同一 Timeline；视频/战术合为标签，Agent/混音器使用 FlexLayout 原生右侧浮出面板。个人宽屏布局不会被窄布局覆盖。
- 成品使用单一预览入口、作品名、源版本和完成时间。详情保留完整文件名、路径和复制反馈；原生视频控制仅在单文件预览出现，不进入 Program Monitor。
- 回放事件优先呈现名字与比赛时间，tick/身份保留精确信息入口。资料库详情采用统一标签和值的对齐轴线，首页移除空待办标题和重复新建动作。

## 验证与边界

- 前端全量测试 3034 项通过；新增覆盖范围/落点与写入一致、非法范围、创建后重试、源预览保留、持久任务恢复、取消状态及窄布局保护。
- Rust 全工作区测试通过；作品任务筛选有真实 SQLite 测试，覆盖不同作品隔离、分页、计数和汇总。
- TypeScript、881 个源码文件的分层检查、严格中英语言目录编译通过。机械设计检查无报告项。
- 原生 Tauri/WebView 验收覆盖宽屏工作区、1100×760、Agent 浮出与 Esc、播放/暂停、回放、高光确认、成品详情、首页和资料库。
- 以 550×380 CSS 视口、DPR 3 对应 1100×760/DPR 1.5 的两倍缩放逻辑视口，检查确认正文可滚动、操作保持可见。这是缩放等效布局检查，不宣称完成所有系统级无障碍测试。
- 首轮渲染后一次修正了窄栏换行、录制片段视觉噪声、成品完成时间取值与高光可见选中位置，随后完成确认，不进行无界视觉迭代。
- 验收只进行了查看、导航、展开、关闭和传输播放头操作。没有新增真实剪辑、录制或导出；实际作品保持 r12、30 个素材、180 秒。原 1440×900/DPR 1.5、个人 Dock 布局和设置页已恢复。

本地设计工具运行状态和重复截图保持在忽略目录；Figma 决策及实现规范以本文件、`apps/web/DESIGN.md` 和既有设计记录为准。
