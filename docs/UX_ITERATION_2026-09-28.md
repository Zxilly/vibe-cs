# 操作体验迭代 · 2026-09-28

起点是一次真实操作走查（开发服务器 + 浏览器 mock，1440×900）。选材、剪辑、录制、交付几条主线都在操作层面“别扭”：模式会自己跳、同一动作多个入口、编辑靠弹窗和表单、失败时显示引擎原文、危险操作占据主位。本轮全部落到代码与 [Figma](https://www.figma.com/design/N05FPVtPTwWV3ONlE48Fwv)，规则写入 `apps/web/DESIGN.md`。

## 选材

- 比赛工作区不再强制切到分析模式；从作品进入（`?project=`）固定为剪辑模式，资料库和比赛页顶部显示选材目标条：目标作品（可切换）、本次已加入数量、返回作品。
- 所有「加入作品」入口（行内、Inspector、批量、回放范围、证据检索）走同一个 `useQuickAddToProject`：有目标作品时直接写入 Story 末尾，提示「已加入 · 撤销」并回退该变更组；只有没有目标作品时才打开弹窗。
- 高光 Inspector 顶部用 2D 回放循环预览高光（含录制前后缓冲，只画主角轨迹）。列表支持 ↑/↓ 切换并播放、空格暂停、A 加入、X 勾选。
- 片段名用选手与高光描述，不再显示内部 ID。

## 剪辑

- 单击片段选中并把播放头移到点击位置，成片预览随 Transport 更新；选中态为 2 px 实线描边。分割与删除不可用时给出原因。同回合多片段标记为 R1a、R1b。
- 片段属性直接编辑：失焦或回车提交一次 Human Edit，Esc 还原，无效输入就地提示；入出点使用时间码，时长只读。保存进行中的修改会提示稍后再改。
- 录制确认说明范围、录制时长和预计用时，提醒 CS2 会占用屏幕与声音，可只录选中的未录制片段。

## 交付与作品

- 成品行的主操作是「播放」「打开所在文件夹」，删除与移除记录收进行菜单；文件名显示在成品列，目录从中间省略。
- 作品卡片显示下一步（待录制、可以导出、去选材）和「继续剪辑」。

## 导航与首次使用

- 侧栏在两种模式下包含同一组入口，当前模式的分组在前，另一模式的入口在底部一组。
- 首次使用不再弹阻断式对话框，工作台显示两张模式卡片。
- 回放选手列表与地图标记按队伍着色。
- 引擎运行时异常不再作为错误原文展示；编辑失败提示浮在页头下方，不挤压时间线；提示框位于底部居中，不遮挡主操作。

## Figma

- 新增「高光选材 · 为作品选材（剪辑模式）」「工作台 · 首次使用（模式卡片）」「片段属性 · 直接编辑」「录制缺失片段 · 确认」画板；原加入弹窗画板标为无目标作品时的兜底。
- 25 份侧栏统一为同一组入口；「玩家目录」统一为「选手目录」；49 处不可见的白色图标与 45 处旧色板选中指示条改绑语义变量；17 处实心蓝分段选择改为浅蓝选中态。
- 成品页、作品页、回放选手列表按代码现状重排；`Module/ProjectTimeline` 与 `TimelineClip/Video` 组件同步工具栏与选中态。

## 开发环境

浏览器 mock 现在会应用 `PATCH /projects/:id` 与变更组撤销，并生成合成的 2D 回放（`src/dev/mockProjectEdits.ts`、`src/dev/mockReplay.ts`），走查不再被 mock 缺口打断。它们只存在于 `pnpm dev`，不是比赛数据。

## 未做与边界

- 成品文件没有重新关联接口，文件缺失的行只保留「移除记录」。
- Figma 回放地图的选手标记是无身份的矢量示意，未按队伍重着色；7 处弹层投影仍为原始值。
- 片段属性沿用时间线修剪的限制：起点为 0 的片段不能再向前移入点。
- 验证：`pnpm lint`、`pnpm typecheck`、层级检查通过，`pnpm test` 304 个文件 3285 项通过；各流程在浏览器 mock 下逐项操作并截图核对。真实 CS2 录制、导出与原生窗口未在本轮重新验收。
