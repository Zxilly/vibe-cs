5. **任务状态不依赖长对话。** 作品顶部固定状态入口；录制/导出分别覆盖运行、失败、取消、重试和完成。Agent 录制有允许/拒绝分支，拒绝与取消运行任务区分。素材就绪、文件生成、技术参数可读和人工观看检查分别表达。
6. **细节与边界。** Program 控件统一 32×32；暂停与质量说明改为用户语言。1100×760 使用共享紧凑 Timeline、视频/战术标签与右侧 Agent 抽屉。200% 文字确认包含长作品名换行、可滚动详情与固定操作。空库导入取消仍返回空库，失败保留源文件。
