# Camera preview fixture

`camera-preview.ts` is generated by the production Rust camera planner over
a synthetic flat floor and a stationary player. It contains no game assets.
The development backend reuses its returned poses and diagnostics; it does not
implement HLAE splines or collision checking in JavaScript.

Regenerate from the repository root in PowerShell:

```powershell
$env:VIBE_CAMERA_SYNTHETIC_FIXTURE_OUTPUT = "$PWD/apps/web/src/dev/fixtures/camera-preview.ts"
cargo test --locked -p vibe-cs-runtime correction_is_deterministic -- --nocapture
```

Real Mirage camera probes remain in the ignored `artifacts/simple-3d` directory.
