# 信息架构重构 · 执行任务清单

> 源文档:`2026-08-19-ia-restructure-prd.md`(问题定义、用户故事编号、模块决策 D1–D7 以此为准)。
> 执行原则:每个任务是纵穿所有层的 tracer bullet,独立完成、独立可验证;完成一个关一个,不顺手做下一个任务的事。

## 纪律(每个任务的完成门,无一例外)

1. `pnpm lint && pnpm typecheck && pnpm test` 全绿才允许勾掉任务(重设计 spec §9 风险 2 的既定纪律)。
2. 保留清单(PRD Further Notes)对应的现有测试只许改断言位置,不许删除。
3. 术语层只管 UI 文案:数据模型、IPC、存储键名、测试 fixtures 的英文标识符不改。
4. 设计系统不动:token、primitives、layout、Blueprint 不新增不改写(PRD D1)。
5. 每任务结束跑一遍浏览器目视检查(agent-browser),截图留证。
